# AI Interview Coach (PartyRock App)

##  Overview
An AI-powered interview simulator built using AWS PartyRock that helps job seekers practice and improve their interview skills with real-time feedback.

## 🎯 Problem
Many candidates struggle with interviews due to lack of practice and feedback.

## 💡 Solution
This app simulates real interview scenarios and provides:
- Dynamic interview questions
- AI-generated feedback
- Improvement suggestions

## 🛠️ Tech Stack
- AWS PartyRock
- Generative AI (LLMs)

## 🧩 Features
- Role-based interview questions (DevOps, Cloud, etc.)
- Answer evaluation
- Feedback scoring system

## 🧠 How It Works
1. User enters role (e.g., Cloud DevOps Engineer)
2. AI generates questions
3. User answers
4. AI evaluates and gives feedback
